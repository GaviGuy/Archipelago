# Variant Sudoku Randomizer Setup Guide

## Required Software

- [Archipelago](https://github.com/ArchipelagoMW/Archipelago/releases/latest)
- A web browser of your choice

## How to play

Start by downloading or generating a template YAML.
Configure the settings to your liking and save the file.

Next, generate and host the multiworld like normal:
[Archipelago Setup Guide](/tutorial/Archipelago/setup_en#generating-a-game)

To connect to a slot, go to the [Variant Sudoku Web Client](https://gaviguy.github.io/VariantSudokuArchipelagoClient/)
and enter the room's address, your slot name, and a password (if applicable), then click "Connect".
Puzzles are found in the 2nd tab.
